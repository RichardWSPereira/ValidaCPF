# Validação de CPF
Validador de CPF em JavaScript — código educativo que implementa as regras oficiais de verificação do CPF.

Sou desenvolvedor e criei este pequeno projeto para demonstrar, de forma clara e didática, como os dígitos verificadores do CPF são calculados. É útil para quem está aprendendo sobre validações numéricas e manipulação de strings em JavaScript.

Principais pontos:

- Implementação em `validaCPF.js` com a função construtora `ValidaCPF`.
- Remove caracteres não numéricos e valida o CPF com a regra oficial de dois dígitos verificadores.
- Detecta e rejeita sequências simples (ex.: 11111111111), consideradas inválidas.

Por que isso importa:

- Validações como essa são comuns em formulários e APIs; entender a lógica por trás melhora a confiança ao implementar validações no backend e frontend.

Exemplo prático:

No arquivo `validaCPF.js` há um exemplo com o CPF `210.774.740-75` que é validado quando o script é executado localmente.
